### Upgrade caveat: quality presets are not an automatic migration

**Release decision, not changed by this preparation:** `RenderVKWaterCaustics` is a new persistent setting with global default1. The feature tables choose0 below High, but both old and new Linux tables remain version33. `llappviewer.cpp` startup applies recommendations only on safe mode, a feature-version/GPU change or ProbeHardwareOnStartup; `llfeaturemanager.cpp::setGraphicsLevel` otherwise applies a preset only when requested. `recordWorld` publishes caustics from the setting and TransparentWater without a separate quality-level gate. Thus an existing low/custom-profile user with no saved caustics value can inherit1 until recommendations/preset are reapplied. It is not correct to promise every upgraded Low user gets caustics off. No automatic broad reset of graphics preferences is recommended. Owner may accept this default, request a narrow one-time initialization respecting explicit preferences, or change the release default; no such policy change was authorized here.

The same preset-versus-saved distinction applies to BlendMaxLights (new global256; preset6/8/16 only when applied) and LayerReuse. Existing explicit persisted values are not forcibly replaced by new defaults. The new RigCullState diagnostic is0/Persist0; its addition rides the GPU-timer merge, not a default-on cache optimization.

Caustics still require the underwater/transparent-water and authoritative sun/moon-shadow conditions; the upgrade caveat is about inherited setting values, not a measured regression in every Low view.
